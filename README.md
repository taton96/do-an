# BOOKING SYSTEM
Hệ thống đặt lịch dịch vụ cho cửa hàng nhỏ.

## Công nghệ
- Frontend: ReactJS + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Authentication: JWT + bcrypt

## Chạy backend
```powershell
cd backend
npm install
copy .env.example .env
npm start
```
Backend: http://localhost:3000

## Chạy frontend
Mở terminal khác:
```powershell
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173
